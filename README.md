This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

it's a simple app that gets some posts data from a fake api [`Dummy JSON`](https://dummyjson.com/)

- get posts and comments is fine.
- but when adding a new one or updating it we make the request only but we can't modify the backend.

## Getting Started

First, to run the development server:

```bash
npm run dev
```

and Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

to run test:

```bash
npm run test
```
